# Upwork Opportunity Intelligence Design System

## Design Principles
- Functionality first, clean SaaS admin dashboard style (shadcn/ui inspired).
- No fancy branding, gradients unless extremely subtle, no illustrations, no decorative marketing UI.
- Dense but readable desktop dashboard. Professional internal tool.
- Light mode: neutral white / gray backgrounds (#FFFFFF, #F8FAFC, #F1F5F9), dark readable text (#0F172A).

## Color System
- Primary Action: Blue (#2563EB)
- Strong Opportunity Signal / Success: Green (#16A34A / #DCFCE7)
- Review / Caution: Amber (#D97706 / #FEF3C7)
- Warning / Risk: Red (#DC2626 / #FEE2E2)
- Neutral Borders: Subtle Slate (#E2E8F0)
- Neutral Cards/Panels: White (#FFFFFF) with subtle border and minimal shadow.

## Typography
- Font Family: Inter
- Standard dense scale with clear hierarchy.

## Components & Spacing
- Corner Roundness: 8px (Medium)
- Buttons: Primary Blue solid, Secondary Outline/Ghost, Small compact padding.
- Cards: White background, 1px slate border, subtle shadow.
- Navigation: Left sidebar dark/light neutral slate, sticky top header with status badges.
